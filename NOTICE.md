# Notices and provenance

## Base academic theme

This project is built on **al-folio**, originally created by Maruan Al-Shedivat and contributors, and distributed under the MIT License. The original license is retained in `LICENSE`.

The initial Jekyll structure used for this NomadLab adaptation came from the supplied academic-site archive, which itself used al-folio. Personal content, identity, and publication records from that archive were removed.

## Nomad Mode

The two-colour experimental interaction and procedural-background idea were informed by the supplied ivmelenen website build as a visual reference.

Nomad Mode was implemented independently for this repository:

- no compiled `_next` JavaScript chunks were copied;
- no font binaries were copied;
- no image or animation assets were copied;
- the mode controller, palette system, responsive styling, WebGL shader, Canvas fallback, and accessibility behavior were written specifically for NomadLab.

Third-party web fonts and icon stylesheets are requested from their upstream CDNs and remain subject to their respective licenses.
